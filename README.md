#  EDA on HR Analytics Data

A comprehensive **Exploratory Data Analysis (EDA)** project on an **HR Analytics dataset** that investigates employee behavior, attrition trends, and factors influencing job satisfaction and retention.  
This project uses Python data analysis libraries to uncover insights that can help organizations reduce attrition and improve workforce stability.

---

##  Project Overview

Employee attrition is a critical challenge for any organization.  
Through this EDA project, we analyze HR data to identify:
- Patterns and correlations in employee demographics
- Key factors driving attrition
- Differences between retained and exited employees
- Insights for HR strategy and employee engagement

---

## 🎯 Objectives

- Clean and preprocess HR employee data  
- Perform exploratory data analysis to identify trends  
- Visualize patterns in attrition, job roles, age, income, and satisfaction  
- Derive actionable insights for HR teams  

---

## 🧰 Tools & Libraries Used

- **Python (3.x)**
- **Pandas** – Data cleaning and manipulation  
- **NumPy** – Numerical analysis  
- **Matplotlib & Seaborn** – Data visualization  
- **Jupyter Notebook** – Interactive exploration
